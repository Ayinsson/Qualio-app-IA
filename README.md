# Qualio-app-IA

Qualio es una aplicacion web para la gestion de pruebas de software y control de calidad. Este repositorio ya tiene estructura base de monorepo para iniciar el MVP.

## Estructura

```text
apps/
  web/   -> React + Vite + TypeScript
  api/   -> NestJS + Prisma + MySQL
docs/    -> Documentacion funcional y tecnica
```

## Primer arranque

```bash
npm install
npm run dev
```

## Scripts raiz

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run test`
- `npm run typecheck`
